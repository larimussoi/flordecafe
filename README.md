**Flor de Café — Landing Page**

Landing page desenvolvida com foco em apresentação institucional, identidade visual marcante e experiência do usuário fluida.

O projeto foi criado com o objetivo de praticar estruturação semântica, estilização responsiva e boas práticas de organização de código front-end.

---

**Demonstração**

🔗 Acesse aqui:(https://flordecafe-pi.vercel.app/)

---

**Tecnologias Utilizadas**

* HTML5
* CSS3
* JavaScript
* Google Fonts

---

**Objetivos do Projeto**

* Criar uma landing page visualmente atrativa
* Trabalhar responsividade
* Aplicar organização modular no CSS
* Melhorar estrutura semântica
* Simular um projeto real para portfólio

---

**Responsividade**

A página foi desenvolvida com layout adaptável para:

* Desktop
* Tablet
* Mobile

Utilizando media queries e boas práticas de design responsivo.

---

**Conceito Visual**

A identidade visual foi pensada para transmitir:

* Aconchego
* Sofisticação
* Naturalidade

Com uso de tipografia elegante, paleta harmônica e seções bem distribuídas.
